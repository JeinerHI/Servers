## E (NginX)
Servidor HTTP, un software **gratuito y de código abierto** que sirve como intermediario entre servidores web y navegadores, permitiendo mostrar sitios web y contenido en Internet.

**Diferencia con Apache:** Nginx es más ligero y maneja mejor la concurrencia. Se usa mucho como reverse proxy y para sitios de alto tráfico.
